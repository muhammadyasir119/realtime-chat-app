# Real-Time Chat Application 🚀

A high-performance, lightweight real-time chat application built with Python FastAPI and WebSockets. This project demonstrates asynchronous event handling and real-time bidirectional communication between clients without page reloads.

---

## 🛠️ Tech Stack
* Backend: Python, FastAPI, Uvicorn
* Frontend: HTML5, CSS3, JavaScript (WebSockets API)
* Protocol: WebSockets

---

## ✨ Features
* Real-Time Messaging: Instant message broadcasting to all connected clients.
* Connection Management: Handles user connections and disconnections dynamically.
* Unique Client IDs: Automatically assigns a unique identifier to each connected chat participant.

---

## 🚀 Getting Started Locally

Follow these steps to run the project on your local machine:

### 1. Clone & Run
git clone https://github.com/Muhammadyasir119/realtime-chat-app.git
cd realtime-chat-app
pip install -r requirements.txt
uvicorn main:app --reload

### 2. Open in Browser
Open your web browser and navigate to:
http://127.0.0.1:8000
